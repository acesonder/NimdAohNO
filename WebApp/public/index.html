About This Tool

📊 Analyze

View MSI package information including product name, version, manufacturer, and installation properties.

📦 Extract

Extract all files from the MSI package to review contents without installing.

📝 Instructions

Get detailed file placement instructions for manual installation without admin privileges.

How to Use

  1. Upload - Select or drag an MSI file
  2. Choose Action - Analyze, extract, or get installation instructions
  3. Review Results - View the analysis or download extracted files
  4. Manual Install - Follow the provided instructions to place files manually

Windows Desktop Application

For direct MSI installation with admin privileges, download our Windows desktop application.

  • ✅ Install MSI files with automatic admin elevation
  • ✅ Extract and analyze MSI packages locally
  • ✅ Get detailed file placement instructions
  • ✅ Works offline on Windows 10/11
